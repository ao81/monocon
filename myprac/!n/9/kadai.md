対象ヘッダ: `ao81/monocon` の `release/monocon_chuugoku.h`

## この課題集について

添付された既出課題集の10問を確認し、目的と中心動作がなるべく重ならないように、新しい10問を作成した。

### 確認した事実

- 対象ヘッダには、入力用として `Di`、`Pr`、`Sok`、`Vr`、`Js`、`Enc`、任意の値を監視する `SigValue` / `sig()` がある
- 出力用として `Led`、`Disp`、`Dcm`、`Spm`、`Bz` がある
- 制御補助として `Seq`、`Iv`、`Ti`、`Sw`、`Tog`、`clamp()`、`wrap()` がある
- 最新版の `Sw::start()` は、停止中に保持された時間から再開する
- `Enc` は初期化時に自動的にポーリングが設定されるため、利用者が `beginPolling()` を呼ぶ必要はない
- `Spm` は `update()` を繰り返し呼ばなければ目標位置へ進まない
- `SigValue` の変化イベントと `Di` / `Pr` のエッジイベントは、読み出されなくても一定のループ数で消える

### 出題上の判断

- 既出の「色カウンタ」「明るさ調整器」「ストップウォッチ」「メロディプレイヤー」「数値入力ダイヤル」「距離警報」「DCモータ往復運転」「ジョイスティック角度制御」「反応速度ゲーム」「搬送ライン」は、新しい問題の主目的にしていない
- 単に全クラスを一度ずつ登場させるのではなく、同じクラスでも異なるメソッドや設計上の注意点を使うようにした
- 測距センサの問題は、正確な距離を測る別の計測器がなくても、物体を動かした方向と表示値の増減から確認できる内容にした
- 内部サービス用メソッドや割り込み処理は課題の対象外とし、通常のスケッチから使う公開APIを中心にした

## 共通ルール

- `setup()` と `loop()` は通常のArduinoスケッチと同じ形で書く
- ヘッダ側が初期化するため、スケッチから `begin()` を呼ばない
- 入力オブジェクトは原則としてグローバルに宣言する
- 長い `delay()` は使わない
- `Di` は最大8個、`Pr` は最大8個、`Sok` は最大2個、`Vr` は最大8個、`Js` は最大4個、`Enc` は最大4個
- 同じアナログピンを複数の入力クラスへ重複登録しない
- `Enc::delta()`、`clampTo()`、`loopTo()` は、いずれも未処理の回転量を読み取って0へ戻す。1ループで複数回呼ばない
- `sig(式)` は、同じ呼び出し位置で毎ループ評価する
- `Seq` の各状態を表す `if (q)` は、毎ループ同じ個数・同じ順序で評価する
- `sm.update(...)` は、ステッピングモータを使う問題では毎ループ通る位置に置く
- DCモータやステッピングモータの回転部へ、手や配線が触れない状態で試験する

# 第1問 ひとつボタンの多機能リモコン ★

## やること

1個のタクトスイッチを、短押し・長押し・長押しして離す、の3種類に使い分ける。

## 使用するもの

| 接続 | 部品 |
| --- | --- |
| `d1` | タクトスイッチ |
| `dp` | 7セグメントLED |
| `led` | RGB LED |
| `bz` | ブザー |

## 動作仕様

1. 起動時は7セグに `OFF`、LEDは消灯とする
2. `d1` を短く押して離すと、動作の有効・無効を切り替える
3. 有効中は7セグに `On`、LEDを緑で点灯する
4. 無効中は7セグに `OFF`、LEDを消灯する
5. `d1` を1秒押し続けた瞬間、LEDを青へ切り替える
6. 1秒以上押したあとで離すと、押していた時間を秒単位で2秒間表示する
7. 長押しを離した操作では、有効・無効を切り替えない
8. 3秒以上押して離した場合だけ、800Hzの音を200ms鳴らす

## できたかの確認

- [ ] すばやい短押しで有効・無効が1回だけ切り替わる
- [ ] 押してから1秒になる前はLEDが青にならない
- [ ] 1秒を越えた瞬間に、押したままでもLEDが青になる
- [ ] 長押しを離しても、有効・無効の状態が反転しない
- [ ] 2.9秒の長押しでは鳴らず、3秒以上では1回だけ鳴る
- [ ] 長押し時間の表示中でも、次の入力を取りこぼさない

## ヒント

- `Di::held(ms, level)` は、指定レベルを一定時間保持した瞬間に1回だけ真になる
- `Di::held(ms, level, true)` は、そのレベルを指定時間以上保ってから反対レベルへ変化したときに真になる
- 短押しと長押しを分けるには、離した瞬間に「長押し成立済みか」を判定する方法がある
- 状態の切り替えには `Tog::flip()`、現在値の取得には `Tog::get()` が使える
- 一時的な結果表示には `Ti` が使える
- 秒表示は、保持時間を自分で計測して `dp.f()` へ渡してもよい

# 第2問 光センサ式コード判定器 ★★

## やること

フォトインタラプタとフォトリフレクタへ入力された順序を読み取り、正しい3手のコードか判定する。

## 使用するもの

| 接続 | 部品 |
| --- | --- |
| `d1` | フォトインタラプタ |
| `a1` | フォトリフレクタ |
| `d2` | リセット用タクトスイッチ |
| `dp` | 7セグメントLED |
| `led` | RGB LED |
| `bz` | ブザー |

## 動作仕様

1. 正解コードを「インタラプタ → リフレクタ → インタラプタ」とする
2. 入力待ちでは、7セグに入力済みの手数 `0`〜`3` を表示する
3. 1手を検出したら、次の入力を受け付けるまで100msの受付禁止時間を設ける
4. 正しい順序で3手入力されたら、LEDを緑にして高い音を1回鳴らす
5. 順序を間違えたら、その時点でLEDを赤にして低い音を1回鳴らす
6. 成功・失敗の結果を2秒表示した後、自動的に0手目へ戻る
7. 1手目の入力後、3秒以内に次の手が来なければ `to` と表示して失敗扱いにする
8. `d2` を押した場合は、どの状態からでも即座に0手目へ戻す

## できたかの確認

- [ ] 正解順だけが成功になる
- [ ] センサを遮ったままでも、同じ入力が連続して数えられない
- [ ] 2個のセンサをほぼ同時に反応させても、1ループ中に2手進まない
- [ ] 3秒の制限時間は各手を入力するたびに最初から数え直される
- [ ] 結果表示中のセンサ入力が次の試行へ残らない
- [ ] リセット直後に正解コードを入れると正常に判定できる

## ヒント

- デジタル側は `Di`、アナログしきい値側は `Pr`
- `Pr::raw()` をデバッグ表示し、遮光時と非遮光時の中間をしきい値にする
- 各センサの「反応した瞬間」だけを使い、`level()` の継続状態を手数として数えない
- 状態ごとの制限時間には `Seq::elapsed()` または `Ti`
- 状態を同じ番号のまま最初からやり直したいときは `Seq::restart()`
- 1ループ中に両方が発生した場合の優先順位を、コード中ではっきり決める

# 第3問 循環式パラメータ設定盤 ★★

## やること

ロータリーエンコーダ1個で、項目選択と値編集を切り替える設定画面を作る。

## 使用するもの

| 接続 | 部品 |
| --- | --- |
| `d1`, `d2` | ロータリーエンコーダA相・B相 |
| `d3` | 決定用タクトスイッチ |
| `d4` | 取消用タクトスイッチ |
| `dp` | 7セグメントLED |
| `led` | RGB LED |

## 動作仕様

1. 設定項目は次の3個とする

   | 項目 | 表示 | 値の範囲 | 範囲端の動作 |
   | --- | --- | --- | --- |
   | 速度 | `SPd` | 0〜255 | 端で停止 |
   | 時間 | `ti` | 1〜30 | 端で停止 |
   | モード | `nd` | 0〜3 | 3の次は0 |

2. 最初は項目選択モードとし、`Enc::delta()` で回転量を1回だけ取得して、3項目を循環選択する
3. `d3` を押すと選択項目の編集モードへ入る
4. 編集モードでは、エンコーダでその項目の値を変更する
5. 速度と時間は範囲端で止まり、モードだけは循環する
6. 編集中に `d3` を押すと値を保存して項目選択へ戻る
7. 編集中に `d4` を押すと変更前の値へ戻して項目選択へ戻る
8. 項目選択中に `d4` を2秒長押しすると、全設定を初期値へ戻す
9. 項目選択中はLEDを青、編集中は黄、保存した瞬間だけ100ms緑にする
10. 項目名と値を700msごとに交互表示する

## できたかの確認

- [ ] 項目は `0 → 1 → 2 → 0` と循環する
- [ ] 速度は255を越えず、時間は1未満にならない
- [ ] モード値は正方向・逆方向の両方で正しく循環する
- [ ] 取消後は編集前の値へ完全に戻る
- [ ] 長押し初期化が1回だけ実行される
- [ ] 表示切替中に回してもエンコーダの回転量を失わない

## ヒント

- 項目選択は `Enc::delta()` の戻り値を現在項目へ加え、`wrap()` で循環させる
- モード値の循環には `Enc::loopTo()`
- 速度と時間の制限には `Enc::clampTo()`
- どちらも内部で回転量を消費するため、同じループで片方だけを呼ぶ
- 編集前の値は別変数へ退避する
- 編集状態には `Tog`、表示切替には別の `Tog` を使える
- `Iv::reset()` を使うと、表示モードを変えた直後の切替時刻を揃えられる

# 第4問 8方向コマンド記憶ゲーム ★★★

## やること

表示された方向列を覚え、ジョイスティックで同じ順序を入力する記憶ゲームを作る。

## 使用するもの

| 接続 | 部品 |
| --- | --- |
| `a1`, `a2` | ジョイスティックX・Y |
| `d1` | 開始用タクトスイッチ |
| `d2` | 向き変更用トグルスイッチ |
| `dp` | 7セグメントLED |
| `led` | RGB LED |
| `bz` | ブザー |

## 動作仕様

1. 0〜7の8方向からなる問題列をランダムに作る
2. 第1ラウンドは2方向、第2ラウンドは3方向とし、最大8方向まで増やす
3. 方向は7セグの自作パターンで、1個ずつ500ms表示する
4. 問題表示後、プレイヤーがジョイスティックを倒して同じ順序を入力する
5. 中央から方向へ倒した瞬間だけを1入力とし、倒したままでは連続入力にしない
6. 入力が正しければ次へ進み、間違えた瞬間にそのラウンドを終了する
7. 1方向につき3秒以内に入力がなければ時間切れとする
8. 全8ラウンド成功で `CLr`、失敗時は成功したラウンド数を表示する
9. `d2` がLOWのときは通常方向、HIGHのときは左右反転した方向として読む
10. ゲーム開始時点の `d2` の状態を固定し、途中で切り替えてもその回には反映しない
11. 回答受付中は、残り秒数を `Ti::remain()` から求めて表示する
12. 正解時と失敗時は、それぞれ3音の短いジングルを `Bz::play()` で再生する

## できたかの確認

- [ ] ジョイスティックを倒したままにしても1入力にしかならない
- [ ] 斜め4方向を含む8方向を区別できる
- [ ] 左右反転モードでは、表示と入力判定が一致する
- [ ] ゲーム途中でトグルを変えても、次のゲームまでは向きが変わらない
- [ ] 問題表示中のジョイスティック操作が回答へ残らない
- [ ] 最大長でも `delay()` を使わず、入力監視が止まらない

## ヒント

- 方向は `Js::dir(8, rot, mirror)` で得られる。中央は `-1`
- `sig(js.dir(...), 30)` のようにすると、方向値の確定にロック時間を持たせられる
- `SigValue::change(-1, 方向)` または `from(-1)` を使うと、中央から倒した変化だけを扱える
- `SigValue::previous()` と現在値を比較してもよい
- 表示パターンは `dp.art()` または `dp(パターン1, パターン2, パターン3)`
- 問題表示、回答受付、結果表示は `Seq` で分ける
- 制限時間が有効かどうかは `Ti::active()`、時間切れの瞬間は `Ti::done()` で判定できる
- ジングル再生中かどうかは `Bz::playing()` で確認できる

# 第5問 相対距離コピー装置 ★★

## やること

測距センサの前に置いた物体を動かし、最初の位置からどちらへ何mm動いたかを表示する。

## 使用するもの

| 接続 | 部品 |
| --- | --- |
| `a1` | 測距センサ |
| `d1` | 基準記録用タクトスイッチ |
| `d2` | 表示切替用タクトスイッチ |
| `dp` | 7セグメントLED |
| `led` | RGB LED |

## 動作仕様

1. 起動直後は `---` と表示し、基準値が未登録であることを示す
2. `d1` を押すと、その時点の距離を基準値として保存する
3. 基準登録後は「現在距離 − 基準距離」をmmで表示する
4. 物体を遠ざけた場合は正、近づけた場合は負で表示する
5. 差が±2mm以内なら0として扱い、LEDを緑にする
6. 差が正ならLEDを青、負ならLEDを赤にする
7. `d2` を押すたびに、差分mm表示とセンサ生値表示を切り替える
8. 基準値から20mm以上離れた状態が500ms続いたときだけ、ブザーの代わりにLEDを50%の明るさで点滅させる
9. 基準を登録し直した瞬間は、差分を必ず0に戻す

## できたかの確認

- [ ] 物体を遠ざけると表示値が増え、近づけると減る
- [ ] 同じ位置で小さく値が揺れても、表示が0付近で激しく変化しない
- [ ] 正確な定規がなくても、動かした方向と符号の一致を確認できる
- [ ] 20mmの境界付近で、点滅が即座に何度も入り切りしない
- [ ] 生値表示から差分表示へ戻しても、基準値が消えない
- [ ] 再登録直後に古い警告状態が残らない

## ヒント

- 距離は `Sok::mm()`、変換前の中央値は `Sok::raw()`
- `sig(差分, ロック時間, 許容差)` の第3引数で、値の小さな揺れを同じ値として扱える
- `SigValue::up()` / `down()` をデバッグに使うと、安定値がどちらへ動いたか確認できる
- 「条件が500ms続いた」は `sig(abs(差分) >= 20).held(500, true)` でも作れる
- 点滅周期には `Iv`、点滅状態には `Tog`

# 第6問 DCモータ・ジョブキュー ★★★

## やること

ボタン操作で短い回転命令を予約し、DCモータが1件ずつ順番に実行する装置を作る。

## 使用するもの

| 接続 | 部品 |
| --- | --- |
| `d1` | 正転ジョブ追加用タクトスイッチ |
| `d2` | 逆転ジョブ追加用タクトスイッチ |
| `d3` | 一時停止用トグルスイッチ |
| `d4` | 全消去用タクトスイッチ |
| `a1` | 速度設定用可変抵抗 |
| `dm` | DCモータ |
| `dp` | 7セグメントLED |
| `led` | RGB LED |

## 動作仕様

1. `d1` を押すと「正転を400ms」、`d2` を押すと「逆転を400ms」のジョブを末尾へ追加する
2. 最大8件まで予約できる
3. モータが停止中でキューにジョブがあれば、先頭のジョブを自動実行する
4. 速度は可変抵抗で80〜255に設定し、ジョブ開始時の値をそのジョブが終わるまで保持する
5. 実行中も新しいジョブを追加できる
6. 7セグには、現在実行中の方向と待ち件数を表示する。例: 正転中で2件待ちなら `F-2`
7. キューが空なら `0`、満杯なら `FUL` を500ms表示する
8. `d3` が停止側になったら、実行中ジョブの終了後に停止する。実行途中では止めない
9. 停止中に `d3` を運転側へ戻すと、残りのキューを続きから実行する
10. `d4` を押すと、実行中でも即座にフリー停止し、全ジョブを消去する
11. 完了した正転・逆転ジョブの合計数を、それぞれ別に記録する

## できたかの確認

- [ ] 正転・逆転を交互に予約すると、押した順番どおりに実行される
- [ ] 実行中に追加したジョブも失われない
- [ ] 9件目を押しても配列外へ書き込まない
- [ ] 一時停止要求は実行中ジョブを途中で切らない
- [ ] 再開後はキューの先頭からではなく、残りから続く
- [ ] 全消去後に `dm.done()` の古い完了通知を誤って数えない
- [ ] ジョブ中にVRを回しても、そのジョブの速度は変わらない

## ヒント

- 方向を格納する8要素のリングバッファを作るとよい
- 時間指定運転は `dm.cw(速度, 400)` / `dm.ccw(速度, 400)`
- 実行中は `dm.busy()`、完了した瞬間は `dm.done()`、現在方向は `dm.dir()`
- 全消去には `dm.fr()`。停止方法をブレーキに変える場合の違いも確認する
- VRは `Vr(a1, 実測最小値, 実測最大値)` とし、`to(80, 255)` で変換する
- `done()` は読むと完了通知が消えるため、毎ループ1回だけ評価する

# 第7問 ステッピングモータ方位校正台 ★★★

## やること

手動送り、絶対角度移動、励磁方式の切替を試せる校正用操作盤を作る。

## 使用するもの

| 接続 | 部品 |
| --- | --- |
| `d1` | 時計回り指令用タクトスイッチ |
| `d2` | 反時計回り指令用タクトスイッチ |
| `d3` | 動作モード切替用タクトスイッチ |
| `d4` | 保持・解放用トグルスイッチ |
| `sm` | ステッピングモータ |
| `dp` | 7セグメントLED |
| `led` | RGB LED |

## 動作仕様

1. 動作モードを次の3種類とする

   | モード | `d1` | `d2` |
   | --- | --- | --- |
   | 0: 1ステップ送り | 1ステップ時計回り | 1ステップ反時計回り |
   | 1: 相対角度送り | +45° | -45° |
   | 2: 180°試験 | 180°へ時計回り指定 | 180°へ反時計回り指定 |

2. `d3` を押すたびにモードを0→1→2→0と切り替える
3. モード0では `cw()` / `ccw()` による1ステップ動作を使う
4. モード1では `rela()` を使う
5. モード2では `abso(180, SHORT, halfDir)` を使い、ちょうど半周の向きを `d1` と `d2` で選ぶ
6. モータ動作中に新しい移動指令が来た場合は、現在の目標に加算せず、その入力を無視する
7. 停止中は現在ステップ位置、動作中は回転方向 `-1` / `1` を7セグに表示する
8. `d4` が保持側なら二相励磁で停止保持し、解放側なら停止後に端子を解放する
9. `d4` の切替は、移動完了後に反映する
10. `d3` を2秒長押しすると、現在位置を0°として再設定する
11. `sm.update(3)` を常に実行する

## できたかの確認

- [ ] モード0は押すたびに1ステップだけ動く
- [ ] モード1で8回同じ方向へ送ると、およそ1周する
- [ ] 0°から180°への移動方向を2種類から選べる
- [ ] モータ移動中の連打で目標位置が増えない
- [ ] `sm.dir()` は移動中だけ `-1` または `1` になる
- [ ] 解放側では停止後にコイルが励磁され続けない
- [ ] ゼロ設定後に `stepPos()` が0になる

## ヒント

- 1ステップ動作は `sm.cw()` / `sm.ccw()`
- 相対移動は `sm.rela()`、絶対移動は `sm.abso()`
- `SHORT` の距離がちょうど180°の場合、最後の引数 `halfDir` が方向を決める
- 動作中は `sm.busy()`、方向は `sm.dir()`、ステップ位置は `sm.stepPos()`
- 二相励磁は `sm._two()`、一相励磁も比較したい場合は `sm._one()`
- 移動完了を `sig(sm.busy()).htol()` で検出すると、完了時に1回だけ `br()` / `fr()` を選べる

# 第8問 3桁表示器テストパターン ★★

## やること

## 使用するもの

# 第9問 2レーン通過順判定器 ★★★★

## やること

2個のフォトインタラプタを通過した順番と時間差から、先着・同着・逆走を判定する。

## 使用するもの

| 接続 | 部品 |
| --- | --- |
| `d1` | レーンAのフォトインタラプタ |
| `d2` | レーンBのフォトインタラプタ |
| `d3` | 計測許可用トグルスイッチ |
| `d4` | リセット用タクトスイッチ |
| `dp` | 7セグメントLED |
| `led` | RGB LED |
| `bz` | ブザー |

## 動作仕様

1. `d3` が停止側の間は `rdy` と表示し、通過を記録しない
2. 運転側へ切り替えた瞬間から、新しい判定を受け付ける
3. AまたはBの最初の遮光で時間計測を開始する
4. もう一方が遮光されたら時間差を確定する
5. 先着から後着までが30ms以内なら同着 `Eq` とする
6. A先着なら `A`、B先着なら `b` と時間差msを交互表示する
7. 先着後2秒経過してももう一方が来なければ `to` とする
8. 同じセンサが、もう一方より先に2回反応したら逆走 `rEu` とする
9. 結果を3秒表示した後、自動で次の判定待ちへ戻る
10. 結果表示中に発生した入力は次回へ持ち越さない
11. 停止側へ切り替えたら、計測途中でも破棄して待機へ戻る
12. `d4` はどの状態でも全記録を消去する

## できたかの確認

- [ ] A先着、B先着、同着、時間切れ、逆走の5種類を判定できる
- [ ] センサを遮ったままでも2回通過した扱いにならない
- [ ] 32ビット時刻の差を符号付きの絶対時刻比較だけで処理していない
- [ ] 計測途中の停止と再開で、古い先着情報が残らない
- [ ] 結果表示の終了と同じ瞬間の入力を誤って次回の先着にしない
- [ ] 同着判定の境界30msをテストできる

## ヒント

- 最初の通過時に `Sw::reset()` と `Sw::start()` を行い、後着時に `Sw::ms()` を読む
- `Sw::running()` で計測中か確認できる
- 状態は `Seq` で「待機・後着待ち・結果表示」に分けられる
- `Seq::in()`、`out()`、`now()` をデバッグ表示すると遷移を確認しやすい
- 結果表示は `Ti::start(3000)`、途中破棄には `Ti::stop()`
- イベントは一度読むと消費されるので、AとBを各ループで1回ずつ変数へ保存してから判定する

# 第10問 探査ステーション管制盤 ★★★★★

## やること

複数の入力から「手動操作」「自動観測」「結果確認」を行う、小型探査ステーションの管制盤を作る。

## 使用するもの

| 接続 | 部品 |
| --- | --- |
| `a1`, `a2` | ジョイスティックX・Y |
| `a3` | 測距センサ |
| `a4` | フォトリフレクタ |
| `d1`, `d2` | ロータリーエンコーダA相・B相 |
| `d3` | 実行用タクトスイッチ |
| `d4` | 手動・自動切替用トグルスイッチ |
| `dm` | 観測用回転台を模したDCモータ |
| `sm` | 方位指示器を模したステッピングモータ |
| `dp` | 7セグメントLED |
| `led` | RGB LED |
| `bz` | ブザー |

## 全体仕様

1. `d4` がLOWなら手動モード、HIGHなら自動観測モードとする
2. モードが変わったら、実行中の動作を安全に停止し、そのモードの初期状態へ移る
3. どの状態でも `sm.update(3)` を実行する
4. 7セグの表示は500msごとに「状態名」と「状態に対応する数値」を切り替える
5. 状態番号が変化したときだけ `DC(状態番号)` でデバッグ出力する

## 手動モードの仕様

1. エンコーダで目標方位を0°、45°、90°、…、315°から循環選択する
2. ジョイスティックの上下でDCモータを正転・逆転させ、中央でフリー停止する
3. ジョイスティックの左右でDCモータ速度を3段階から選ぶ
4. `d3` を押すと、ステッピングモータを選択方位へ最短回りで移動させる
5. 移動中に `d3` を押すと `sm.stop()` でその場停止する
6. LEDの色で、DCモータ正転・逆転・停止を区別する

## 自動観測モードの仕様

1. `d3` を押すと1回の自動観測を開始する
2. 開始時点の距離を保存する
3. DCモータを速度160で1秒だけ正転させる
4. DCモータ完了後、ステッピングモータを90°ずつ4地点へ移動する
5. 各地点で300ms待ってから、距離とフォトリフレクタ生値を1回ずつ記録する
6. 4地点の観測後、最も距離が短かった方位へ戻る
7. 同じ最短値が複数あれば、最初に観測した方位を選ぶ
8. フォトリフレクタ値が開始時より一定値以上変化した地点数も数える
9. 結果表示では、最短方位、最短距離、変化地点数を順番に表示する
10. 結果表示中に `d3` を押すと、同じ観測結果を先頭から再表示する
11. 結果表示中に `d3` を2秒長押しすると、記録を消して自動観測待機へ戻る

## 異常時の仕様

1. 観測中に測距値が500mmへ張り付いた状態が1秒続いたら、センサ異常として停止する
2. 異常時はDCモータをブレーキ、ステッピングモータを停止・解放する
3. 7セグに `Err`、LEDを赤、ブザーを200ms間隔で3回鳴らす
4. エラー音を鳴らしている最中でも、モード切替を受け付ける

## できたかの確認

- [ ] 手動モードと自動モードで、同じ入力が別の意味として正しく働く
- [ ] モード変更時に、前モードのタイマ・エッジ・目標位置が残らない
- [ ] 自動観測の順序が「DC完了 → 方位移動 → 待機 → 記録」を守る
- [ ] 4地点の配列外へ書き込まない
- [ ] 最短値が同じ場合の結果が毎回同じになる
- [ ] 結果の再表示では観測をやり直さない
- [ ] エラー音に `delay()` を使わず、途中のモード変更が効く
- [ ] `dm.done()`、エンコーダ回転量、入力エッジを各ループで重複して読まない
- [ ] デバッグ出力に、意図しない状態遷移や同一状態の連続出力がない

## ヒント

- 全体を1個の巨大な状態番号にせず、モードと自動観測用 `Seq` を分けると整理しやすい
- モード変化は `sig(ts).change()` のように検出できる
- 方位選択は `Enc::loopTo(index, 0, 7)` と `index * 45`
- ジョイスティックは `Js::dir(4)` と `x()` / `y()` を用途で使い分ける
- DCモータの終了検出は `dm.done()`
- ステッピングモータの到着は `sig(sm.busy()).htol()`
- 観測点到着後の安定待ちは `Ti`
- 500mmが続いた判定には `sig(sok.mm(), 10, 許容差)` の `held()`、または条件をboolへした `sig()` を使う
- 結果再表示には `Seq::restart()` が使える
- `Iv::wait()` / `go()` を使う場合は、モード切替で周期の残り時間を保持するのか、`reset()` するのかを明確に決める
- エラー音3回は `Seq`、`Iv`、カウンタを組み合わせ、非ブロッキングで作る
