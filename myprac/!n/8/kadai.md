## 共通ルール

- `setup()` と `loop()` は普通の Arduino スケッチと同じように書く。ヘッダが内部で `userSetup` / `userLoop` に置き換えてくれる
- `begin()` を自分で呼ぶ必要はない
- `Di` / `Vr` / `Enc` などのオブジェクトはグローバルに置く
- `delay()` を長く使わない。`delay()` 中は `Spm::update()` と `Seq` が進まない。周期処理は `Iv` / `Ti` / `Sw` で作る
- 登録できる個数に上限がある。**Di 8個 / Pr 8個 / Enc 4個 / Sok 2個**。超えた分は無言で動かなくなる
- ビルド前に `Disp::artPattern` の `constexpr` を外しておく。Arduino IDE は C++11 なので、そのままではコンパイルが通らない
- 7セグの明るさ（`dp.o()`）を下げると、`loop()` が重いときにちらつく。動作確認は実機で行う

# 第1問 カラーカウンタ ★

## やること

スイッチを押すたびに RGB LED の色を切り替え、今何番目かを7セグに表示する。

## 動作仕様

1. 起動時は LED 消灯、7セグに `0` を表示する
2. `d1` を押した瞬間に色番号が 1 増える。離した時ではない
3. 色番号と色の対応は次の通り

   | 番号 | 色 |
   | --- | --- |
   | 0 | 消灯 |
   | 1 | 赤 |
   | 2 | 緑 |
   | 3 | 青 |

4. 3 の次は 0 に戻る
5. 7セグには色番号を右詰めで表示する

## できたかの確認

- [ ] スイッチを押しっぱなしにしても番号は 1 しか進まない
- [ ] 3 の次に 0 へ戻る
- [ ] 素早く連打しても、押した回数と番号の進み方が一致する
- [ ] チャタリングで一度に 2 個進むことがない

## ヒント

- 押した瞬間の検出は `Di` の `ltoh()`（LOW→HIGH）か `htol()`（HIGH→LOW）。どちらが「押した瞬間」になるかは基板の配線で決まるので、両方試して確かめる
- 押しっぱなしの状態を知りたいときは `level()`
- 0〜3 を巡回させるなら `wrap()` が使える。`if` で書いてもよい
- 色の定数は `R` `G` `B` がヘッダに用意されている
- 数字の表示は `dp.n()`

# 第2問 明るさコントローラ ★

## やること

可変抵抗で7セグの明るさを変えながら、その値を数値でも表示する。

## 動作仕様

1. `a1` に可変抵抗をつなぐ
2. VR を回すと7セグの明るさが 0%〜100% の範囲で変化する
3. 7セグには現在の明るさ（0〜100）を表示する
4. `d1` を押すたびに、表示が「10進」と「16進」で切り替わる
5. 16進のときは同じ値を16進3桁で表示する（例: 100 → `064`）

## できたかの確認

- [ ] VR を右端まで回したとき、ちゃんと 100 になる（途中で頭打ちにならない）
- [ ] VR を左端まで回すと 0 になる
- [ ] 10進と16進の切り替えが、押すたびに交互になる
- [ ] 明るさを一番暗くしたとき、数字が読めるかどうか確認する

## ヒント

- `Vr` のコンストラクタは `Vr(ピン, 入力の最小値, 入力の最大値)`。**既定値のままだと ADC の上半分が使えない**ので、ここを直す必要がある
- 0〜100 への変換は `Vr::to(0, 100)`
- 明るさの設定は `dp.o()`。3桁まとめてでも桁ごとでも指定できる
- 16進表示は `dp.base(値, 16)`
- 表示モードの切り替えには `Tog` が使える
- 明るさ 0% にすると数字が完全に消える。仕様上どう扱うか自分で決めてよい（下限を 5% にするなど）

# 第3問 ストップウォッチ ★★

## やること

スタート・一時停止・リセットができるストップウォッチを作る。

## 動作仕様

1. `d1` を押すたびに、計測開始と一時停止が切り替わる
2. `d2` を押すと 0 にリセットする
3. 7セグに経過時間を「秒」で表示する。桁数は値によって変える

   | 経過時間 | 表示例 |
   | --- | --- |
   | 10秒未満 | `1.23` |
   | 10秒以上100秒未満 | `12.3` |
   | 100秒以上 | `123` |

4. 計測中は LED を緑、停止中は赤にする
5. 999秒を超えたら計測を止め、7セグに `End` を表示する

## できたかの確認

- [ ] 一時停止してから再開すると、**続きから**進む（0 に戻らない）
- [ ] 一時停止中に表示が止まっている
- [ ] リセットは計測中でも停止中でも効く
- [ ] 小数点の位置が桁の増減に合わせて自動で移動する

## ヒント

- 経過ミリ秒は `Sw::ms()` で取れる。ただし `Sw::start()` は 0 に戻す作りなので、**一時停止からの再開は `Sw` だけでは足りない**。停止した時点までの合計を自分で覚えておく
- 秒に直した値を `dp.f()` に渡すと、小数点の位置は自動で決まる。仕様3はほぼそのまま実現できる
- 押すたびの切り替えは `Tog` と `Di::ltoh()` の組み合わせ
- 文字の表示は `dp.s("End")`

# 第4問 メロディプレイヤー ★★

## やること

3曲を選んで再生できるプレイヤーを作る。

## 動作仕様

1. 3曲分の音階データを配列で用意する。1曲あたり8音以上
2. `d1` を押すと次の曲を選ぶ。選んだ曲番号（1〜3）を7セグに表示する
3. `d2` を押すと選んだ曲を再生する
4. 再生中は LED を青で点灯し、再生が終わったら消灯する
5. 再生中に `d2` をもう一度押すと停止する
6. `d3` を押しながら `d2` を押すと、繰り返し再生になる
7. 繰り返し再生中も `d2` で止められる

## できたかの確認

- [ ] 再生中に `d1` で曲を切り替えても、音が混ざったり途中で固まったりしない
- [ ] 曲の最後まで再生されたら、自動で LED が消える
- [ ] 繰り返し再生が確実に止まる
- [ ] 休符を入れた曲でも、そこで止まらずに進む

## ヒント

- 再生は `bz.play(音階配列, 長さ配列, 音数, 繰り返しするか)`
- 音階と長さは別々の `int` 配列。周波数に 0 を入れるとその区間は休符になる
- 再生中かどうかは `bz.playing()`
- 曲の切り替えは、`play()` に渡す配列を差し替えるだけでよい
- 「押しながら」は `Di::level()`（押されている状態）と `ltoh()`（押した瞬間）の組み合わせで作る
- ドレミの周波数は自分で調べて定数にする

# 第5問 数値入力ダイヤル ★★

## やること

ロータリーエンコーダで数値を入力し、長押しで確定する UI を作る。

## 動作仕様

1. ロータリーエンコーダの A 相を `d1`、B 相を `d2` につなぐ
2. 回すと値が 0〜999 の範囲で増減する。範囲外には出ない
3. 現在値を7セグに3桁ゼロ埋めで表示する（例: 7 → `007`）
4. `d3` を 1 秒以上長押しすると値が確定し、LED が緑に光る
5. 確定後にエンコーダを回すと LED が消え、また編集できるようになる
6. `d4` を押すと値が 0 に戻る

## できたかの確認

- [ ] 速く回しても取りこぼさない
- [ ] 999 で止まる。1000 にならない
- [ ] 0 で止まる。-1 にならない
- [ ] 長押しは 1 回だけ発火する。押し続けても繰り返し確定しない
- [ ] 確定 → 回す → また長押し、が何度でもできる

## ヒント

- `Enc::clampTo(現在値, 下限, 上限)` が、範囲制限つきの加算をまとめてやってくれる
- `Enc::delta()` は読むと 0 にリセットされる。**1周に 1 回だけ**呼ぶこと。2回呼ぶと2回目は必ず 0 になる
- 長押しの判定は `held(1000, H)`。`H` の部分は基板の配線に合わせる
- ゼロ埋め表示は `dp.n(値, true)`
- 「回された」ことの検出は、`delta()` の戻り値が 0 かどうかで判断する

# 第6問 距離センサ警報 ★★★

## やること

測距センサの値で色を変え、しきい値を越えた瞬間だけ音を鳴らす。

## 動作仕様

1. 測距センサを `a1` につなぐ
2. 距離を cm で7セグに表示する
3. 距離で LED の色を変える

   | 距離 | 色 |
   | --- | --- |
   | 30cm 未満 | 赤 |
   | 30cm 以上 45cm 未満 | 黄 |
   | 45cm 以上 | 緑 |

4. 30cm を下回った**瞬間だけ** 100ms の短い音を鳴らす。近づけ続けても鳴り続けない
5. 境界付近で色や音がバタつかないよう、切り替えに 2cm の幅を持たせる
6. `d1` を押している間はブザーを鳴らさない（消音モード）

## できたかの確認

- [ ] 30cm ちょうどの位置で手を止めても、色がチカチカしない
- [ ] ゆっくり近づけたとき、ブザーは 1 回だけ鳴る
- [ ] 一度遠ざけてから再度近づけると、また 1 回鳴る
- [ ] 消音モード中に境界をまたいでも、解除後に音が溜まって鳴ったりしない

## ヒント

- 距離は `Sok::cm()`（float）または `Sok::mm()`（int）
- 「条件を満たした瞬間」を取るには `sig(条件).ltoh()` が使える。ただし `sig()` は**毎周必ず評価する**こと。`if` の中に入れて評価されない周があると壊れる
- バタつき対策は、近づくときと離れるときでしきい値を変える。たとえば「28cm を切ったら赤」「32cm を超えたら黄に戻る」
- 短い音は `bz(周波数, 時間ms)`
- 黄色の定数は `Y`（`GR` と同じ）
- `Sok` の内部では5サンプルの中央値を取っているので、自分で平均を取る必要は基本的にない

# 第7問 DCモータの往復運転 ★★★

## やること

DC モータを決まった手順で往復させ、途中で止められるようにする。

## 動作仕様

1. `d1` を押すと運転を開始し、次の手順を繰り返す

   ```
   正転 2秒 → 停止 1秒 → 逆転 2秒 → 停止 1秒
   ```

2. 各段階で7セグに文字を表示する

   | 段階 | 表示 |
   | --- | --- |
   | 待機中 | `---` |
   | 正転 | `Fwd` |
   | 停止 | `stp` |
   | 逆転 | `rEu` |

3. `d2` を押すと、どの段階でも即座にブレーキをかけて待機に戻る
4. 回転速度は `a1` の可変抵抗で 0〜255 の範囲で変えられる
5. 往復した回数を数え、10 往復したら自動停止して7セグに `End` を表示する
6. `End` の状態で `d1` を押すと、カウンタを 0 に戻して最初からやり直す

## できたかの確認

- [ ] `d2` の緊急停止が、正転中・逆転中・停止中のどの段階でも効く
- [ ] 速度を変えても各段階の時間は 2秒 / 1秒 のまま変わらない
- [ ] 運転中に VR を回すと、その場で速度が変わる
- [ ] ちょうど 10 往復で止まる。9 や 11 にならない
- [ ] ブレーキ（`br`）とフリー（`fr`）の違いを実際に触って確かめた

## ヒント

- 段階の進行には `Seq` が向いている。`Seq::on()` は**毎周同じ回数・同じ順番で**呼ぶのが条件。`if` の中に入れて呼ばれない周があると状態番号がずれる
- 各段階の経過時間は `Seq::after(ms)` で見られる
- `dm.cw(速度, 時間ms)` を使うと時間で自動停止し、`dm.done()` で終了を検知できる。ただし `Seq` の時間管理と併用すると二重管理になりやすいので、どちらかに寄せる
- `dm.br()` はブレーキ、`dm.fr()` はフリー。止まり方が違う
- 文字の表示は `dp.s("Fwd")`

# 第8問 ステッピングモータの角度制御 ★★★

## やること

ジョイスティックで目標角度を指定し、最短回りで動かす。

## 動作仕様

1. ジョイスティックの X を `a1`、Y を `a2` につなぐ
2. 倒した方向で目標角度を決める

   | 方向 | 目標角度 |
   | --- | --- |
   | 上 | 0° |
   | 右 | 90° |
   | 下 | 180° |
   | 左 | 270° |

3. 目標角度へは常に最短回りで動かす
4. 停止しているときは、現在の角度（0〜359）を7セグに表示する
5. 移動中は7セグに回転アニメーションを表示する。3桁を使って、外周のセグメントが1周まわるように見せる
6. アニメーションの1コマは 80ms ごとに進める
7. `d1` を押すと、現在の位置を 0° として設定し直す

## できたかの確認

- [ ] 350° から 10° へ動かすとき、逆回りで 340° 分も回らない
- [ ] ジョイスティックを離しても動き続け、目標に着いたら止まる
- [ ] アニメーションの速さが `loop()` の重さで変わらない
- [ ] 目標に着いた瞬間、アニメーションから角度表示にきれいに切り替わる

## ヒント

- 方向の取得は `Js::dir(4)`。倒していないときは `-1` が返るので、そのときは目標を変えない
- 目標角度の指定は `Spm::abso(角度, SHORT)`。`SHORT` が最短回り
- **`Spm::update(間隔ms)` を毎周呼ばないとモータは動かない。** `delay()` の中では呼ばれないので、`delay()` は使わない
- 動作中かどうかは `Spm::busy()`、現在角度は `Spm::pos()`
- 位置のリセットは `Spm::zero()`
- 一定周期の処理は `Iv`
- 自作のセグメントパターンは `dp.art("...", "...", "...")` で作る。文字列の **i 番目が `.` なら i 番目のセグメントが光る**

  | 位置 | セグメント |
  | --- | --- |
  | 0 | a（上） |
  | 1 | b（右上） |
  | 2 | c（右下） |
  | 3 | d（下） |
  | 4 | e（左下） |
  | 5 | f（左上） |
  | 6 | g（中央） |
  | 7 | 小数点 |

- `art()` は**文字列リテラルしか渡せない**（`const char*` の変数は渡せない）。コマを配列で持ちたいときは、パターンを自分で計算して `dp(a, b, c)` に直接渡す方法もある。どちらで作るか考えてみること

# 第9問 反応速度ゲーム ★★★★

## やること

LED が光ってからボタンを押すまでの時間を測るゲームを作る。

## 動作仕様

1. `d1` を押すとゲーム開始
2. 1〜3秒のランダムな時間だけ待つ。この間 LED は赤
3. 時間が来たら LED を緑にして、同時に短くブザーを鳴らす
4. 緑になってから `d1` を押すまでの時間を ms 単位で計測し、7セグに表示する
5. 緑になる前に押したらフライング。7セグに `FUL` を表示し、低い音を長めに鳴らして、その回は無効にする
6. 1回の結果を2秒表示したら、次の回へ進む。これを3回繰り返す
7. 3回終わったら、有効だった回の平均を出し、ゆっくり点滅させながら表示する
8. `d2` を押すと、いつでも最初からやり直せる

## できたかの確認

- [ ] フライングした回は平均に含まれない
- [ ] 3回とも有効だったときの平均が正しい
- [ ] 3回ともフライングだったとき、平均の計算で 0 割りしない
- [ ] 999ms を超える反応時間でも表示が破綻しない
- [ ] `d2` のリセットが、待機中・計測中・結果表示中のどこでも効く
- [ ] フライング後にそのまま押し続けても、次の回に持ち越されない

## ヒント

- 全体の進行を `Seq` で「待機 / ランダム待ち / 計測 / 結果表示 / 集計」に分けると整理しやすい
- 各状態に入った瞬間だけ実行したい処理は `Seq::in()`。状態を出る直前だけなら `Seq::out()`
- ランダムな待ち時間は `random(1000, 3001)`。乱数の種はライブラリ側で設定済みなので `randomSeed()` は不要
- 待ち時間の管理は `Ti::start()` と `Ti::done()`。残り時間は `Ti::remain()`
- 反応時間の計測は `Sw`
- フライングは「計測状態に入る前にボタンが押されたか」で判定する
- `dp.n()` は範囲外を無言で 999 に丸める。仕様4でそれを許すかどうか自分で決める
- 点滅は `Iv` と `Tog`、または `dp.o()` の明るさを 0 と 100 で切り替える方法もある

# 第10問 搬送ライン模擬 ★★★★

## やること

ここまでの部品を全部組み合わせて、小さな自動機の動きを作る。

## 装置の構成

| 部品 | 役割 |
| --- | --- |
| `a1` フォトセンサ | ワークがコンベア入口に来たことを検出する |
| `a2` 測距センサ | ワークまでの距離を測り、仕分け先を決める |
| DC モータ | コンベア |
| ステッピングモータ | 仕分けアーム |
| `d1` | 起動 / 停止 |
| `d2` | リセット |

## 動作仕様

1. 起動前は待機状態。7セグに `rdy`、LED は消灯
2. `d1` を押すと運転開始。コンベアを速度 180 で正転させ、LED を緑にする
3. フォトセンサがワークを検出したら、コンベアをブレーキで止める
4. 止まった状態で測距センサを読み、仕分け先を決める

   | 距離 | 仕分け先 | アームの角度 |
   | --- | --- | --- |
   | 100mm 未満 | A | 0° |
   | 100mm 以上 250mm 未満 | B | 120° |
   | 250mm 以上 | C | 240° |

5. アームを目標角度へ動かす。動いている間はコンベアを止めたままにする
6. アームが目標に着いたらブザーを1回鳴らし、コンベアを再開する
7. 処理したワークの数を数える。7セグには「仕分け先の文字」と「累計個数」を1秒ずつ交互に表示する
8. 運転中に `d1` をもう一度押すと、その場でコンベアをブレーキして待機に戻る
9. `d2` はどの状態でも効く。アームを 0° に戻し、カウンタを 0 にクリアして待機状態にする

## できたかの確認

- [ ] 1個のワークを2回数えない
- [ ] アームが動いている間、コンベアが動き出さない
- [ ] 停止してから再開したとき、途中の状態が残っていない
- [ ] リセット直後にすぐ `d1` を押しても正常に動く
- [ ] ワークを連続で流しても、仕分け先の判定がずれない
- [ ] `#define dbg` を付けてシリアルに状態遷移を出したとき、想定外の遷移が出ない

## ヒント

- 状態管理は `Seq`。「入った瞬間」は `Seq::in()`、「出る直前」は `Seq::out()`
- フォトセンサは `Pr`。しきい値はコンストラクタの第2引数で決める。実機で `Pr::raw()` の値を見ながら決めること
- **注意**: `Vr` や `ar()` で読んだアナログピンは、`DIDR` の設定によりデジタル読みができなくなる。`a1` を `Pr` で使うなら、同じピンを `Di` や `dr()` で読まないこと
- `Sok` は内部で5サンプルの中央値を取っている。仕様4で自分で平均を取る必要があるかどうか、実測して判断する
- 交互表示は `Iv` で1秒ごとに切り替える
- 状態の見える化には `D()` / `DV()` / `DC()` マクロが使える。スケッチの先頭で `#define dbg` を書いてから `#include` する。`DC(x)` は値が変わったときだけ出力するので、状態遷移の確認に向いている
- 状態が増えると `Seq::on()` の呼び順を崩しやすい。処理を関数へ切り出すときも、毎周必ず全部の `on()` を通ることを確認する
- 完成したら、ワークを2個連続で流したときの挙動を必ず確かめる

# 付録: 詰まったときの確認ポイント

| 症状 | 疑うところ |
| --- | --- |
| スイッチが全く反応しない | `Di` の登録数が 8 個を超えていないか。オーバーすると無言で動かなくなる |
| アナログピンのデジタル読みが常に LOW | 同じピンを `Vr` / `Pr` / `ar()` で使っていないか |
| 7セグが暗いとちらつく | `loop()` が重い。`delay()` を減らすか、明るさを上げる |
| ステッピングモータが動かない | `Spm::update()` を毎周呼んでいるか。`delay()` の中では呼ばれない |
| エンコーダの値が増えない | `Enc::delta()` を1周に2回以上呼んでいないか。2回目は必ず 0 になる |
| `Seq` の状態がずれる | `Seq::on()` が毎周同じ回数・同じ順で呼ばれているか |
| `sig()` が反応しない | 毎周評価されているか。`if` の中に入っていないか |
| ビルドが通らない | `Disp::artPattern` の `constexpr` を外したか。ボード選択が Mega 2560 になっているか |
